#  Nairobi Matatu Intelligence System

A data-driven transport analytics platform built with **Python, SQL, Machine Learning, and Streamlit** to simulate and analyze Nairobi's matatu ecosystem.

## 📌 Overview

The Nairobi Matatu Intelligence System transforms raw transport data into actionable insights for operators, SACCOs, commuters, and transport planners. The platform combines data engineering, business intelligence, and machine learning to provide route performance analytics, fare predictions, traffic insights, and operational recommendations.

## ✨ Features

* 📊 Interactive executive dashboard
* 🚦 Traffic and congestion analysis
* 💰 Revenue and profitability tracking
* 🏆 SACCO performance leaderboard
* 🔍 Advanced SQL analytics
* 🤖 Machine Learning fare prediction
* 🛣️ Route recommendation engine
* 📈 Interactive visualizations and KPIs

## 🛠️ Tech Stack
